Skills

物理阶段目录

  1. 每次选择一个 skill + 参数组合，闭环执行最多 10 步；连续相同调用延续轨迹。
  2. 手臂由环境角色和目标绑定，无需模型选择。
  3. target：注册位姿。
  4. height_ref：task / standby / travel。
  5. depth_fraction：0.25 / 0.5 / 1。
  6. 躯干朝向：相对 HOME 为 0°、±45°、±90°、−120°。
  7. Rules：使用预定义 sequence 和内部参数。
#Skill参数动作含义夹爪
1rotate_torsofacing_angle_degJOINT_POSITION/absolute：A1 转到 HOME 相对 0°、±45°、±90°、−120°；保持其他手臂关节角保持
2wait—保持进入时的固定目标位姿；夹爪输入为 0保持
3keep—保持位姿和夹爪开度保持
4approachtarget移动到目标位姿打开
5ascendheight_ref竖直上升到指定高度打开
6descendtarget竖直下降；持物时保持夹爪闭合空爪打开／持物闭合
7carrytarget持物仅沿世界坐标 XY 水平移动；保持高度与姿态闭合
8liftheight_ref持物竖直上升到指定高度闭合
9lowertarget持物竖直下降到放置高度闭合
10pressdepth_fraction从固定起点竖直下压指定深度闭合
11withdrawtarget退到指定待机位姿打开
12open_gripper—原地打开夹爪打开
13close_gripper—原地闭合夹爪闭合
14rotate_grippertargetOSC_POSE：沿控制件注册轴走圆弧；一般旋转保持 XYZ保持
15open_hinge—沿铰链轨迹打开门或盖子闭合
16close_hinge—沿铰链轨迹关闭门或盖子闭合

cd /Users/dddogwang/Desktop/Maholo/maholo_auto
/Users/dddogwang/miniforge3/envs/mujoco_env/bin/python -m experiment.scripts.common.run_method \
  --method rules --mode skills --task-id L1.reach_target \
  --task-instance Pipette005 --chunk-horizon 10 --max-decisions 80
