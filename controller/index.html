默认连接

BASIC → JOINT_POSITION + GRIP

`default_maholo.json` 让左右机械臂使用关节位置控制器，并将每个 MaholoGripper 映射为一维 `GRIP` 控制器。

查看 JSON 配置
Python
from robosuite import load_controller_config

controller_config = load_controller_config(
    default_controller="JOINT_POSITION"
)

env = suite.make(
    env_name="MaholoLaboratory",
    robots="MaholoWithRight",
    controller_configs=controller_config,
)

动作范围

选择足够而不过量的接口。

对 Maholo 变体而言，机械臂关节维度之外，每个主动机械臂再配一个夹爪维度；组合控制器还可能增加其他身体部件通道。

MaholoWith*15 个机器人关节 + 2 个夹爪维度双臂
MaholoRight / Left8 个机器人关节 + 1 个夹爪维度单臂
MaholoOnlyRight / Left7 个机械臂关节 + 1 个夹爪维度固定底座机械臂

用于 RL 实验

保持控制器对比公平。

比较算法时固定机器人变体、控制频率和动作归一化方式。

将组合/部件控制器配置与回合一起记录；控制器选择会改变策略接口。

只有在基准协议允许特权对象观测时，才使用任务状态传感器。
