L1

原子能力

到达、抓取、释放、抬升、搬运、放置、按压、旋转、开关。

L2

组合工作流

围绕单个设备组合 L1 操作。

L3

跨设备工作流

协调多个设备与对象的阶段。

import numpy as np
from robosuite.environments.manipulation.maholoLevel1Env import MaholoLevel1Single
from robosuite.utils.maholo_grasp import fixed_grasp_config

env = MaholoLevel1Single(
    robots="MaholoRight",
    task_id="L1.grasp_object",
    target_instance="Pipette005",
    target_config={**fixed_grasp_config("Pipette005"), "position_tolerance": 0.02},
    use_camera_obs=False,
    use_object_obs=True,
    has_renderer=False,
    has_offscreen_renderer=False,
    renderer="mujoco",
    horizon=1000,
)
obs = env.reset()
obs, reward, done, info = env.step(np.zeros(env.action_dim))
env.close()
