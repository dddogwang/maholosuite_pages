快速开始

启动原生查看器。

先运行维护中的 demo 检查完整 Maholo 场景，再编写策略。

终端

查看场景的最快方式

mjpython -m robosuite.demos.visual_maholo
使用环境中的 mjpython，让 MuJoCo 与原生查看器运行在同一套环境中。
Python
import robosuite as suite
from robosuite import load_controller_config

env = suite.make(
    env_name="MaholoLaboratory",
    robots="MaholoWithRight",
    controller_configs=load_controller_config(
        default_controller="JOINT_POSITION"
    ),
    has_renderer=True,
    renderer="mjviewer",
)
env.reset()
env.render()

模型契约

四层结构，一个实验。

每个任务都由明确的场景 / 机器人 / 控制器边界组装而成。

01

场景

MaholoArena 加载台面、底座、设备、架子、工具、视觉网格和碰撞组。

02

机器人

选择双臂、单臂或固定底座变体，同时保持夹爪接口一致。

03

任务

目标解析器和状态机暴露成功判定、进度、事实与失败原因。

04

策略

归一化动作经过组合控制器和部件控制器，最终进入 MuJoCo 执行器。

解释边界。

几何、关节、接触、qpos、目标位姿和控制器输出属于仿真状态。仅凭接触不能推断液体体积、温度场、混合结果、污染、反应动力学或生物学结果。
